## 📖 О проекте

**CRYPTOISK Trading Platform** — это вторая часть комплексного образовательного проекта, представляющая собой **полностью независимую** торговую площадку. В отличие от CRM-системы, этот код **написан с нуля** и не является форком какого-либо открытого продукта.

Платформа имитирует личный кабинет клиента криптобиржи и работает в связке с CRM-системой (call-центр). Проект создан для **обучения следователей** методам выявления и документирования мошеннических схем в сфере криптотрейдинга.

**Ключевая особенность:** все данные (балансы, транзакции, карты) являются **вымышленными**. Платформа не подключается к реальным платежным шлюзам и не проводит финансовых операций.

---

## 🔗 Взаимосвязь с CRM

Оба проекта используют **общую базу данных** (`krayin_crm`), но логически разделены:
*   **CRM (call-центр):** операторы управляют клиентами, видят их активность, одобряют пополнения и выводы средств.
*   **Трейдинговая платформа (личный кабинет):** клиент регистрируется, пополняет счет, открывает позиции Buy/Sell, видит графики и оформляет заявки на вывод.

Связь между проектами осуществляется через:
*   Общие таблицы `users`, `persons`, `leads` (клиент, зарегистрированный на площадке, автоматически появляется в CRM как лид).
*   Журнал событий `trading_events` (действия клиента передаются в CRM для отображения в истории).
*   API-мост для ручного изменения баланса (оператор CRM может начислять или списывать средства).

## 🚀 Установка и запуск

### Требования
*   PHP >= 8.3
*   Composer
*   MySQL (с базой от CRM)
*   Node.js & NPM (только для CRM, трейдингу не требуется)

### Шаги установки

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/klimeastwood/crypto-trading.git
    cd crypto-trading
    ```

2.  **Установите зависимости:**
    ```bash
    composer install --prefer-source
    ```
    *(Используйте `--prefer-source`, если возникают проблемы с загрузкой архивов GitHub).*

3.  **Настройте окружение:**
    *   Скопируйте `.env.example` в `.env`.
    *   Укажите подключение к базе `krayin_crm` (той же, что у CRM).
    *   Сгенерируйте ключ: `php artisan key:generate`.

4.  **Создайте таблицы платформы:**
    ```bash
    php artisan migrate
    ```
    *(Миграции аддитивные: создаются только таблицы `trading_accounts`, `trading_positions`, `price_history`, `trading_events`, `withdrawal_cards`, `withdrawal_requests`).*

5.  **Загрузите исторические цены:**
    ```bash
    php artisan trading:fetch-prices
    ```

6.  **Запустите сервер:**
    ```bash
    php artisan serve --port=8001
    ```

7.  **Доступ:**
    *   URL: `http://127.0.0.1:8001`
    *   Регистрация: `http://127.0.0.1:8001/register`
    *   Вход: по учетным данным, созданным при регистрации (или выданным оператором CRM).

## 🛡️ Защита общей базы

Поскольку платформа использует общую базу с CRM, встроена защита от случайного удаления данных:
*   Команды `migrate:fresh`, `migrate:refresh`, `migrate:reset` и `db:wipe` **блокируются**, если в базе обнаружены таблицы CRM.
*   Отключить защиту можно через `TRADING_PROTECT_SHARED_DB=false` в `.env`, но делать это **не рекомендуется**.

---

## 📊 Данные рынка (CoinGecko)

Цены загружаются через бесплатный публичный API CoinGecko. Команда `trading:fetch-prices`:
*   Загружает историю за 7 дней (настраивается).
*   Сохраняет тики в `price_history` (с дедупликацией).
*   Имеет ретраи на случай сетевых ошибок.

Автообновление раз в час:
```bash
php artisan schedule:work
```
